## Learning Path

A practical progression is:

1. Start with **Fuzz the Query Key** and **Blues in the Fuzz** to build familiarity with fuzzing concepts.
2. Continue with **Find the Hidden Files** and **Robots in the Crawl** for web discovery.
3. Move to **ZIP It, Crack It** and **ZIP Lock Blues** for archive-focused challenges.
4. Explore **FTP Drop and Crack**, **Anonymous FTP Blues**, and **FTP Secrets Pivot Paths** for FTP security concepts.
5. Study **Dripline Discovery** and **Drip and Crack** for Drip-themed discovery and cracking challenges.
6. Finish with **Nmap Script Sleuth** for network reconnaissance and Nmap scripting.

## How to Use the Labs

1. Open each lab through its direct Learn SecByte link.
2. Review the supplied scope and instructions before starting.
3. Perform all exercises only inside authorized lab environments.
4. Record discovered files, paths, services, clues, and relevant observations.
5. Focus on understanding the security concept behind each challenge.
6. Document lessons learned for future CTF and defensive-security practice.

## Learning Goals

- Practice web query fuzzing.
- Discover hidden files and web paths.
- Understand robots.txt as a web reconnaissance clue.
- Explore ZIP and archive security challenges.
- Investigate FTP and anonymous FTP concepts.
- Develop structured network reconnaissance habits.
- Explore Nmap scripting in a controlled CTF environment.
- Build repeatable enumeration methodology.
